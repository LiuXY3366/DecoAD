Stage 1\
（1）将视频中的人进行骨骼提取\
（2）将骨骼视频与场景视频进行聚类（Pose1、Pose2、Pose3...  Scene1、Scene2、Scene3...）\
（3）计算Pose之间的相似度（距离）、计算Scene之间的相似度（距离）\
（4）构建知识图谱\
Stage 2（重组扩大训练集）\
（1）如果两个场景的距离相差较小，但其正常的动作相差较大则重组为正常训练数据\
（2）如果两个场景的距离相差较小，但其异常的动作相差较大则重组为异常训练数据\
（3）如果两个场景的距离相差较大，且其正常的动作相差较大则重组为异常训练数据\
（4）如果两个场景的距离相差较大，且一个场景中异常的动作与另一个场景中正常的动作相差较小，重组为新的异常训练数据与正常训练数据\
